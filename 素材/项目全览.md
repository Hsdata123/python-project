## 一、项目是什么

把千川（巨量引擎）投放数据从「人工导 Excel → 手工导入」改造为「API 自动同步 → 自动打标报表」的全链路自动化系统。

**三个仓库**：

| 仓库 | 位置 | 作用 | 远程 |
|---|---|---|---|
| api_data_sync | `D:\python project\api_data_sync` | 数据同步框架（core + qianchuan/console/wangdiantong 三服务） | GitHub `Hsdata123/api_data_sync` |
| python project | `D:\python project\python project` | 报表脚本（sucai/dou_puls/订单）+ 素材目录 | GitHub `Hsdata123/python-project` |
| api_data_sync_v2_disabled | `D:\python project\api_data_sync_v2_disabled` | 已停用的副本（中间过渡用） | 无 |

## 三、每日自动链路（全部在 Ubuntu）

| 时间 | 任务 | 端点/脚本 |
|---|---|---|
| 05:30~06:10 | 账户日报 ×6 | all_promotion 系列 |
| 06:10 | 全域素材-直播间画面 | live_material_daily |
| 06:20 | 乘方直播间画面 | overall_live_material_daily |
| **06:30** | **乘方素材（核心）** | **overall_material_daily（type_v3=3）** |
| 06:40 | 乘方抖音号小时 | overall_aweme_hourly |
| 06:45 | 其他创意 | overall_other_daily |
| 03:00/04:00/04:20 | 运维（raw清理/自检补拉/刷账户） | |
| **07:00** | **打标报表** | **sucai-report.timer → sucai_every_month_api.py** |

- 每次同步 = **水位 -2 天 ~ 昨天**（近 3 天回流窗口，UPSERT 覆盖平台修订）
- 前置检查：打标脚本运行前检查素材端点状态 success 且行数>0，否则退出
- 同步范围：**仅 2 账户** `1757724572785671`（官方）+ `1875393773286089`（人参#6089）
- 人参#6571 / 个人护理#1002 已停投（include_in_sync=0），恢复时改回 1

## 七、关键踩坑记录（防止重蹈覆辙）

| # | 坑 | 解法 |
|---|---|---|
| 1 | `roi2_material_type_v3` 筛选仅接受单值 | 逐类型循环请求 |
| 2 | type_v3=1（标题）拉到的素材无名称/播放/创建时间 | **必须用 type_v3=3（视频）** |
| 3 | 行内 type 标注随机漂移（"视频"↔"直播间画面"） | 已删该列，唯一键回归 3 元组 |
| 4 | 多行 upsert 键集不一致 → MySQL `Unknown column 'new.xxx'` | loader 按键集分组 |
| 5 | 启动自检从表最小日期白扫历史段 | 给历史段写 no_data 占位日志 |
| 6 | Jinja 模板 block 外的 `<script>` 被整体丢弃 | script 放 block 内 + 闭合标签 |
| 7 | 老表迁移行 account_id 被哑账户覆盖为 '0' | 传真实 advertiser_id 的 Account |
| 8 | 素材创建时间历史值含 '全部' 脏值 | REGEXP '^20xx-xx-xx' 过滤 |
| 9 | Ctrl+F5 强刷前页面按钮无反应 | 浏览器缓存旧页面（Jinja 修复后需强刷） |
| 10 | Ubuntu venv 缺 numpy/pandas | pip install（2026-09-30 已装） |
| 11 | api_sync 账户缺 qianchuan_sucai 读权限 | 已删映射逻辑（API 自带名称，无需跨库读） |
| 12 | 旧库 t_sucai_daily_report 无主键 | 新表建在 qianchuan 库，PK(素材ID+账号名称+日期) |
