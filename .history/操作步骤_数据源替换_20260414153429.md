# dou_puls.py 百应数据源替换操作步骤

## 一、需求概述

将百应流量综合趋势数据的数据来源由本地Excel文件替换为数据库中的数据表。千川数据配置保持不变。

## 二、数据库配置

### 千川数据库（保持不变）
```python
DB_CONFIG = {
    'host': 'localhost',
    'database': 'qianchuan_sucai',
    ...
}
```

### 百应数据库（新增）
```python
BAIYIN_DB_CONFIG = {
    'host': 'localhost',
    'database': 'baiyin_data',
    ...
}
```

## 三、数据表映射

| 代码变量 | 数据库表 |
|---------|---------|
| baiyin_df_modify | traffic_trend |

### 账号名称映射
| live_room参数值 | 数据库账号名称 |
|----------------|---------------|
| 鱼子酱 | 弹动官方旗舰店 |
| 椰子 | 弹动个人护理旗舰店 |

**注意**：数据库表含有账号名称列，根据live_room参数映射后筛选。

## 四、SQL编写要求

- 表名：`traffic_trend`
- 筛选条件：`账号名称 = '{映射后的账号名称}'`
- 入参：live_room（鱼子酱/椰子）

## 五、代码修改内容

### 1. 新增百应数据库配置
```python
BAIYIN_DB_CONFIG = {
    'host': 'localhost',
    'user': 'root',
    'password': '123456',
    'database': 'baiyin_data',
    'charset': 'utf8mb4'
}

LIVE_ROOM_MAPPING = {
    "鱼子酱": "弹动官方旗舰店",
    "椰子": "弹动个人护理旗舰店"
}
```

### 2. 新增百应数据获取函数
```python
def get_baiyin_traffic_from_db(live_room):
    """从百应数据库获取流量综合趋势数据"""
    account_name = LIVE_ROOM_MAPPING.get(live_room)
    connection = pymysql.connect(**BAIYIN_DB_CONFIG)
    try:
        query = f"SELECT * FROM traffic_trend WHERE `账号名称`='{account_name}'"
        df = pd.read_sql(query, connection)
        return df
    finally:
        connection.close()
```

### 3. 修改 merge_baiyin_qianchuan_data 函数
- 移除：`baiyin_df = concat_file_list_data(file_list)` 等Excel读取逻辑
- 改为：`baiyin_df = get_baiyin_traffic_from_db(live_room)`

## 六、日期格式注意事项

- 百应数据需要保持 `时间` 列，格式为 `YYYY/MM/DD HH:MM`
- 后续处理会将其转换为 `日期-小时` 格式进行merge
